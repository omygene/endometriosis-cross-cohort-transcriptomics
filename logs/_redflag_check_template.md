# SX Red Flag Check — stage disaster-hunt (one-shot)

**Rule (registered 2026-09-13, lead's protocol addition, binding for all stages):**
run ONCE per stage, after the stage's outputs are independently verified (R2) and
BEFORE the R3 gate opens the next dependent stage. Disaster-hunting only — no
open-ended critique, no continuous re-review.

**Grading:**
- 🔴 **Blocker** — must be dispositioned before the next stage opens: fix, or a documented Amendment.
- 🔵 **Note** — recorded here and in the final study report; no action now.

**Verdict line (mandatory):** `BLOCKERS: n` — if n = 0 the stage closes officially.
